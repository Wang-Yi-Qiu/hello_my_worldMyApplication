## 📡 API 使用示例

### 多项式运算

```bash
curl -X POST "http://localhost:5000/polynomial/roots" \
  -H "Content-Type: application/json" \
  -d '{
    "coefficients": [1, -5, 6],
    "variable": "x"
  }'

# 响应
{
  "success": true,
  "roots": [
    {"real": 3.0, "imag": 0.0},
    {"real": 2.0, "imag": 0.0}
  ],
  "num_roots": 2
}
```

### 复数运算

```bash
curl -X POST "http://localhost:5000/complex/operations" \
  -H "Content-Type: application/json" \
  -d '{
    "real1": 3,
    "imag1": 4,
    "real2": 1,
    "imag2": -2,
    "operation": "multiply"
  }'

# 响应
{
  "success": true,
  "real": 11.0,
  "imag": -2.0
}
```

### 微分方程求解

```bash
curl -X POST "http://localhost:5000/ode/solve" \
  -H "Content-Type: application/json" \
  -d '{
    "equation_type": "second_order_constant",
    "parameters": {"a": 2, "b": 1},
    "initial_condition": {"y0": 1, "dy0": 0},
    "time_range": [0, 10]
  }'

# 响应
{
  "success": true,
  "equation_type": "second_order_constant_coefficient",
  "general_solution": "C1*exp(r1*x) + C2*exp(r2*x)",
  "discriminant": 0.0
}
```

### 函数优化

```bash
curl -X POST "http://localhost:5000/optimize" \
  -H "Content-Type: application/json" \
  -d '{
    "function_code": "x**2 - 4*x + 3",
    "initial_guess": [5.0],
    "method": "BFGS"
  }'

# 响应
{
  "success": true,
  "optimal_point": [2.0],
  "optimal_value": -1.0,
  "iterations": 2
}
```

### 插值

```bash
curl -X POST "http://localhost:5000/interpolate" \
  -H "Content-Type: application/json" \
  -d '{
    "points": [
      {"x": 0, "y": 1},
      {"x": 1, "y": 3},
      {"x": 2, "y": 7},
      {"x": 3, "y": 13}
    ],
    "method": "lagrange"
  }'
```

### 数值求根

```bash
curl -X POST "http://localhost:5000/root_finding?expression=x%5E2%20-%204&method=newton&initial_guess=3"

# 响应
{
  "success": true,
  "method": "newton",
  "root": 2.0,
  "value_at_root": 0.0
}
```

## 🔐 安全建议

### 生产环境配置

1. **修改 CORS 设置**

```python
# 只允许特定域名访问
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://your-domain.com"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

2. **添加身份验证**

```python
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

security = HTTPBearer()

@app.post("/execute")
async def execute_code(
    request: ExecuteRequest,
    credentials: HTTPAuthorizationCredentials = Depends(security)
):
    # 验证 token
    token = credentials.credentials
    if not validate_token(token):
        raise HTTPException(status_code=401, detail="Invalid token")
    # ... 继续处理
```

3. **限制计算时间**

```python
import signal

@app.post("/execute")
async def execute_code(request: ExecuteRequest):
    # 设置超时
    def timeout_handler(signum, frame):
        raise TimeoutError("Computation timeout")
    
    signal.signal(signal.SIGALRM, timeout_handler)
    signal.alarm(request.timeout)
    
    try:
        result = eval(request.code)
        signal.alarm(0)
        return result
    except TimeoutError:
        return {"success": False, "error": "Timeout"}
```

## 🐳 Docker 部署

创建 `backend/Dockerfile`:

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 5000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]
```

构建和运行：

```bash
docker build -t smartcalc-backend .
docker run -d -p 5000:5000 smartcalc-backend
```
